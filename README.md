## 使用

把对应 skill 目录拷到你的 agent skills 目录，或按你所用平台的 skill 安装方式引用本仓库中的路径。

每个 skill 以目录为单位，入口是该目录下的 `SKILL.md`。本仓库归档副本；有更新时以各 skill 的上游仓库为准。
